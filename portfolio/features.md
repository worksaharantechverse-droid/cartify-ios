# Features — Cartify

## Verified in the iOS 26 simulator

- Shop tab with product grid, category chips and search.
- Product detail with description and add-to-cart.
- Cart tab with quantity steppers and removal.
- `SAVE10` promo code and live totals.
- Simulated checkout confirmation.
- Cart persistence across launches.
- Light and dark appearance.

## Verification note

Unit and UI tests are authored and compile, but execution was skipped at the user's request.

## Physical-device checks

No hardware-only flows; all payments are simulated locally.
